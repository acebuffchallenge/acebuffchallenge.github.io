도전낚시 개인정보처리방침

시행일: 2026년 10월 22일

1. 처리하는 정보와 목적

낚시 일정·예약 메모, 준비물, 선택한 지역·낚시 방식, 저장한 포인트는 기능 제공을 위해 기기에 저장됩니다. 회원가입이나 자체 계정 기능은 없습니다.

2. 위치 권한

현재 위치 표시 기능에서 이용자가 위치 접근을 허용한 경우 기기의 위치 정보를 사용합니다. 위치 권한은 휴대폰 설정에서 철회할 수 있습니다. 백그라운드 위치 권한은 요청하지 않습니다.

3. 인터넷 연결과 외부 서비스

날씨·조석 등 정보 조회 시 선택 지역, 관측소, 날짜 등 조회에 필요한 정보가 해당 데이터 제공 서비스로 전달됩니다. 지도 화면은 OpenStreetMap 지도 타일을 요청하며, 표시 범위에 해당하는 타일 좌표와 접속 IP 등 통신 정보가 외부 서비스에서 처리될 수 있습니다. 외부 지도·검색·유튜브 링크를 열면 해당 서비스의 정책이 적용됩니다. 저장한 예약 메모와 포인트 목록을 운영자 서버로 전송하는 자체 기능은 포함하지 않습니다.

4. 보관 및 삭제

기기에 저장한 정보는 해당 기능의 삭제 메뉴 또는 Android 설정의 앱 저장공간 데이터 삭제로 지울 수 있습니다. 앱 데이터 삭제 시 저장한 일정과 포인트도 삭제될 수 있습니다. 이 배포본은 앱 백업 허용을 해제합니다.

5. 광고와 개인정보 선택

이 앱은 Google AdMob 배너 광고와 Google 사용자 메시징 플랫폼(UMP) SDK를 사용합니다. 광고 제공, 보안·부정 사용 방지, 광고 성과 측정 등을 위해 IP 주소, 광고 식별자 등 기기·계정 식별 정보, 앱 실행·광고 상호작용 정보, 진단 정보가 Google로 전송·처리될 수 있습니다. IP 주소를 통해 대략적인 위치가 추정될 수 있습니다. 앱이 사용하는 정밀 위치 좌표를 광고 SDK에 직접 전달하는 기능은 포함하지 않습니다. 적용 지역과 동의 상태에 따라 광고 개인정보 선택 화면이 제공됩니다. 선택 변경이 필요한 경우 화면 하단의 ‘광고 개인정보 설정’에서 변경할 수 있습니다. Android 설정의 광고 개인정보 보호 메뉴에서도 관련 설정을 관리할 수 있습니다. Google 개인정보처리방침: https://policies.google.com/privacy Google의 파트너 서비스 데이터 이용: https://policies.google.com/technologies/partner-sites

6. 이용자 권리와 문의

권한 철회 및 기기 데이터 삭제는 휴대폰 설정에서 할 수 있습니다. 개인정보 관련 문의: acebuffchallenge@gmail.com (도전낚시 운영자).

7. 변경 안내

기능이나 외부 서비스의 변경에 따라 방침을 수정하고 앱 또는 게시 페이지에서 안내합니다.
